# SentinelLite AI

SentinelLite AI is a lightweight Linux endpoint detection and monitoring agent with AI-assisted alert analysis.

The project starts as a Python CLI tool focused on defensive Linux security monitoring. It is designed to collect security-relevant events, apply transparent detection rules, calculate risk levels, generate JSON reports, and provide human-readable defensive explanations.

## Current Status

Version: `v0.1.0`

Current milestone:

- Project foundation
- Python package structure
- CLI startup
- System information display
- Monitoring module roadmap

## Planned Monitoring Modules

- Authentication log monitoring
- Process monitoring
- Network connection monitoring
- Open port monitoring
- File integrity monitoring
- Risk scoring
- JSON report generation
- AI-assisted alert explanation

## Security Scope

SentinelLite AI is a defensive cybersecurity project.

It is intended for:

- Linux endpoint monitoring
- log analysis
- security learning
- lab testing
- defensive alerting
- safe reporting

It is not intended for malware, credential theft, unauthorized exploitation, backdoors, persistence payloads, or destructive activity.

## Development Note

The tool can be developed on macOS, but the target monitoring environment is Linux.

On macOS, SentinelLite AI runs in development mode. Full monitoring features will be tested inside Linux environments such as ARM64 Linux VMs.
